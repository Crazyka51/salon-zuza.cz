# Salon Zuza Mobile Admin

Mobilní aplikace pro správu rezervací salonu Zuza.

## Hlavní funkce
- Přehled rezervací v reálném čase.
- Kalendář a správa termínů.
- Dashboard s denními metrikami.
- Detail rezervace s rychlým kontaktem na zákazníka.
- Změna stavu rezervací přímo z mobilu.
- Bezpečné přihlášení a správa relací.
- Podpora pro offline režim (ukládání změn při výpadku připojení).

## Technické informace
Aplikace je postavena na frameworku **React Native** s využitím **Expo**. Komunikuje s produkčním API na adrese `salon-zuza.cz`.

### Přihlášení
Uživatelé používají stejné přihlašovací údaje jako do webové administrace. Aplikace si bezpečně pamatuje přihlášeného uživatele i jeho údaje pro rychlý přístup.

### Oznámení
Aplikace podporuje systémová oznámení pro důležité události (vyžaduje udělení oprávnění při prvním spuštění).
